# touchpad-gestures

Монолитный демон жестов тачпада на C++26 для Linux (проверено: Arch + Niri + PipeWire,
Huawei MagicBook X14 2022, Goodix GXTP7863).

Читает сырые evdev-события тачпада и управляет мультимедиа через D-Bus (MPRIS) и
громкостью через libpulse — **без единого fork-а процессов**.

**Универсально:** тачпад определяется автоматически по возможностям ядра
(ABS_MT-координаты + BTN_TOUCH) — работает с Goodix, ELAN, Synaptics, RMI и любыми
другими; клавиатура для DWT — тоже по возможностям, без имён устройств.

## Потребление

| | |
|---|---|
| RAM | ~1–2 МБ RSS |
| CPU в простое | 0% (блокирующий `poll()`) |
| Процессы-потомки | нет |

(для сравнения: прежняя python-версия на evdev + wpctl/playerctl — 27 МБ и форки на каждое событие)

## Жесты

| Жест | Действие |
|---|---|
| Палец по правому краю вверх/вниз | Громкость = позиция пальца |
| Два пальца по правому краю, свайп вниз | Play / Pause |
| Палец по левому краю вверх | Следующий трек |
| Палец по левому краю вниз | Предыдущий трек |
| Двойной тап по левому краю | Play / Pause |

Любой MPRIS-плеер: Яндекс Музыка, YouTube в браузере, VLC, mpv, Spotify —
команды идут через `playerctld` (D-Bus авто-запуск), он сам выбирает активный плеер.
Громкость системная (общая для всех приложений).

## Защита от случайных касаний

- **DWT** (disable-while-typing): жесты подавлены 400 мс после последней нажатой
  клавиши; касание, начатое во время печати, гасится целиком до отрыва пальца
- **arm-зона**: жест срабатывает только если касание *началось* в этой зоне
  (ладонь, скользнувшая из центра на край, ничего не сделает)
- **`MT_TOOL_PALM`**: касания, помеченные драйвером как ладонь, игнорируются
- **пороги намерения**: громкость взводится после ≥25 px движения, смена трека —
  при ≥60 px и скорости ≥0.15 px/мс (медленный дрейф не срабатывает)

## Установка

```bash
./install.sh              # пользовательская (без sudo, рекомендуется)
./install.sh --system     # в /usr/local/bin (нужен sudo)
./install.sh --uninstall  # удалить
```

Зависимости: `cmake gcc pkgconf libevdev dbus libpulse`
(Arch: `sudo pacman -S cmake gcc pkgconf libevdev dbus libpulse`).

Установщик соберёт демон, поставит udev-правило при необходимости, установит и
включит systemd user-сервис, проверит, что он активен.

## Ручная сборка

```bash
make                      # cmake + build в ./build
./build/touchpad-gestures -v     # запуск вручную с логами
./build/touchpad-gestures --set-volume 50   # самопроверка pulse-пути
```

## Конфигурация

Все пороги — константами вверху `main.cpp` (после правки `make && ./install.sh`):

```cpp
ARM_MOVE_PX = 25          // «взвод» жеста громкости, px
TRACK_THRESHOLD = 60      // порог смены трека, px
TRACK_COOLDOWN_MS = 400   // кулдаун между сменами треков
TWO_SWIPE_THRESHOLD = 120 // двухпальцевый свайп вниз, px
TAP_MOVE_THRESHOLD = 20   // смещение, отменяющее тап, px
DOUBLE_TAP_TIMEOUT_MS = 400
TYPING_GUARD_MS = 400     // окно DWT, мс
```

Пороги — в пикселях ABS-координат устройства (диапазон читается с тачпада
автоматически, зоны — доли ширины). На тачпаде с другой физической плотностью
пороги `TRACK_THRESHOLD`/`ARM_MOVE_PX` может понадобиться подстроить под себя.

## Диагностика

```bash
systemctl --user status touchpad-gestures
journalctl --user -u touchpad-gestures -f      # логи в реальном времени
```
